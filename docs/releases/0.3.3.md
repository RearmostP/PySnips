# PySnips 0.3.3

שיפורים מאז גרסה 0.3.0:

- מסך בית מסודר עם כותרת, תיאורים ושני כרטיסי פעולה: שליפים והגדרות.
- תמיכה במסך בית צר, בעברית וב־RTL, ובערכות הנושא הבהירה והכהה.
- עיצוב משותף לערכות הנושא עם צבעים סמנטיים ואייקונים המתעדכנים לפי העיצוב.
- ארגון האייקונים ושימוש עקבי בהם ברחבי הממשק.
- הצמדת קטגוריות וניהול קטגוריות שנמחקו בסל המחזור.

קובצי ההפצה:

- `PySnips-0.3.3-Setup.exe` — מתקין Windows הכולל את האפליקציה והמעדכן העצמאי.
- `PySnips-0.3.3-Setup.exe.sha256` — בדיקת שלמות למתקין, המשמשת גם את המעדכן.

נתוני המשתמש וההגדרות הקיימים נשמרים בעדכון.
