# PySnips V2

ספרייה מקומית לשליפים, Markdown וקבצים נלווים, באמצעות Python ו־PySide6.

## הפעלה

בסביבת Python של הפרויקט:

```powershell
python -m pip install -r requirements.txt
python main.py
```

המימוש נבדק על Windows עם Python 3.14.5 ו־PySide6 6.11.2.

האפליקציה כוללת בית, שליפים והגדרות. במסך השליפים אפשר ליצור קטגוריה ושליף,
לחפש בכותרות, בתגיות ובתוכן. כרטיסי השליפים מציגים Markdown עם צביעת קוד
וכפתורי פרטים, עריכה ומחיקה. העתקת Markdown זמינה בתפריט הלחיצה הימנית
של התוכן; דיאלוג העריכה מאפשר גם שינוי קטגוריה.
אפשר לצרף קבצים בזמן יצירה או עריכה; תמונות וקישורים נכתבים כנתיבים יחסיים.

בהגדרות אפשר לשנות שפה וערכת נושא, לבחור פתיחה ישירות בשליפים,
לפתוח את דיאלוג השליפים שנמחקו ולבנות מחדש את החיפוש.

## נתונים

ברירת המחדל היא `data/` לצד הפרויקט. אפשר לבחור תיקיית נתונים אחרת לפני
ההפעלה באמצעות משתנה הסביבה `PYSNIPS_DATA_DIR`.

```text
data/
├── user_data/
│   ├── snips/
│   │   ├── categories.json
│   │   └── <category>/<disk_name>/
│   │       ├── snippet.md
│   │       ├── metadata.json
│   │       └── media/
│   └── trash/snips/<id>/
└── system_data/
    ├── settings/settings.json
    └── search_index/
```

תיקיות וקובצי תמיכה נוצרים כשנדרשים. הגדרות חסרות מחזירות ברירות מחדל;
קובץ ההגדרות נוצר רק בשמירה הראשונה. קובצי נתונים פגומים אינם נדרסים
אוטומטית. האינדקס ניתן למחיקה: החיפוש יבנה אותו שוב מקובצי השליפים.

## בדיקות

```powershell
$env:QT_QPA_PLATFORM = 'offscreen'
python -m unittest discover -s tests -v
```

הבדיקות משתמשות בתיקיות זמניות ואינן משנות את ספריית השליפים שלך.

לפרטי המבנה, הבחירות והשינויים בפורמט: [תיעוד ה־rewrite](docs/rewrite.md).
